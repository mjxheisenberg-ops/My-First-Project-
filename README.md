# Daily Task Tracker

A beginner-friendly task tracker made with plain HTML, CSS, and JavaScript.

## Features

- Add tasks to your daily list
- Mark tasks as complete
- Delete individual tasks
- Clear all completed tasks
- Automatically save tasks in your browser using local storage
- Responsive layout for mobile and desktop

## Run the project

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add a task and try the controls.

No installation, build tools, or API keys are required.

## Project files

- `index.html` — page structure
- `style.css` — layout and visual styling
- `script.js` — task interactions and local storage

## Built with

HTML5, CSS3, and vanilla JavaScript.

## Learning goals

This project demonstrates DOM manipulation, event handling, arrays, and browser local storage.
